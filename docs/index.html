Blueprint Nexus Connection Guide

100% Client-Side Engine: This dashboard works completely offline! You can drop any .litematic or .nbt file right now to inspect layers, 3D voxels, and materials without needing any server running.

Connecting from GitHub Pages (HTTPS to HTTP): Browsers block unencrypted requests (http://localhost:8080) from HTTPS pages by default (Mixed Content). To connect live in-game:

  • Option A: In Chrome/Edge, click the padlock/settings icon on the left of the URL bar > Site Settings > Set Insecure content to Allow.
  • Option B: Open the server's internal portal URL directly in your browser: http://localhost:8080 (served by the plugin itself with no mixed content restrictions!).
  • Option C: Use an HTTPS tunnel like ngrok or Cloudflare Tunnel (e.g. https://your-domain.ngrok-free.app).

Player Quota (15 MB): Each player has a dedicated 15 MB storage quota. Malicious blocks (Command Blocks, Bedrock, Barriers) are automatically filtered for server safety.
